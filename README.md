# The Letters — TTPD-inspired archive

A dark, distressed, typewriter-style personal letter archive inspired by the mood of *The Tortured Poets Department* — not an official Taylor Swift site.

## Current version
- Classic homepage/card arrangement restored
- Original dark gray/black homepage background restored
- 18 muted paper variations retained
- Centered letter modal with direct opening (no envelope)
- Falling paper effect retained
- 100 individually editable letter objects in `script.js`
- Search across letters
- Spotify placeholders
- Rotating homepage/side thoughts removed

## Easy editing
### Homepage — `index.html`
Edit the header text near the top of the file.

### Letters — `script.js`
Each of the 100 letters is written out separately. Edit:
- `person`
- `date`
- `song`
- `artist`
- `spotifyId`
- `keywords`
- `preview`
- `text`

### Paper variations
The paper style cycles through 18 designs automatically. You do not need to edit anything for this.

## GitHub Pages
Upload/extract the three site files (`index.html`, `style.css`, `script.js`) into the root of your repository, commit them, and refresh the Pages site. Use Ctrl+Shift+R for a hard refresh if an old version is cached.
